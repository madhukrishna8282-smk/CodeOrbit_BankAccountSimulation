# CodeOrbit_BankAccountSimulation
Java program to simulate bank account operations such as deposit,withdrawl and balance checking
CodeOrbit Bank Account Simulation

Description

A simple Java console application that simulates basic bank account operations.

Features

- Deposit money into an account
- Withdraw money from an account
- Check the current account balance
- Validate deposit and withdrawal amounts
- Display an error for insufficient balance
- Exit the application

Technologies Used

- Java
- Scanner class for user input
- Switch statement and do-while loop

How to Run

1. Open the project in Eclipse IDE.
2. Create or open "BankAccountSimulation.java".
3. Run the Java program.
4. Select an option from the bank account menu.
5. Follow the instructions displayed on the console.
